# 디자이너 트렌드 레이더

IT 기업 UX 디자이너를 위한 주간 트렌드 앱입니다. iPhone Safari에서 열어 홈 화면에 추가하면 앱처럼 쓸 수 있습니다.

- **홈**: 이번 주 브리핑, 핵심 수치, 꼭 볼 이슈
- **직무**: NHN 2025 UX 설계 디자이너 JD를 기준점으로, 국내(토스·당근·카카오·네이버 등)와 해외(미국·캐나다·호주·영국)에서 늘어나는/줄어드는 직무, 실제 공고, 요구 스킬 변화
- **이슈**: AI 모델·디자인 툴·깃허브·빅테크·규제·국내 소식을 한국어로 요약. 각 항목에 "디자이너에게 왜 중요한지" 한 줄과 원문 링크
- **저장**: 북마크 (기기 브라우저에만 저장)

## 파일

| 파일 | 역할 |
|---|---|
| `app.html` | 화면·스타일·동작 (데이터는 `__SEED__` 자리에 주입) |
| `seed.json` | 콘텐츠 데이터. 이 파일만 고치면 내용이 바뀝니다 |
| `build.py` | `seed.json`을 `app.html`에 넣어 `index.html`(단독 실행용)과 claude.ai 배포용 조각을 만듭니다 |
| `index.html` | 빌드 결과물. 브라우저에서 바로 열 수 있습니다 |

빌드: `python3 build.py`

## 데이터 구조 (seed.json)

- `meta`: 브리핑 헤드라인, 불릿, 수치 타일, 출처 노트
- `tags`: 이슈 분류 키 → 표시명
- `news[]`: `id, date, title, summary, why, url, tags[], pick(홈 노출), rumor(루머/예정 표시)`
- `jobs.kr`: `jd`(기준 JD), `up[]`, `down[]`, `postings[]`
- `jobs.global.byCountry.{us,ca,au,uk}`: `summary, stats[], up[], down[], postings[]`
- `jobs.skills.items[]`: 요구 스킬 지표

## claude.ai 배포판

claude.ai 아티팩트로 배포된 버전은 두 가지 기능이 더 있습니다.

- 이슈 카드의 **「쉽게 설명」**: 해당 항목 내용만 근거로 Claude가 더 풀어서 설명 (처음 한 번 허용 확인)
- **데이터 저장소 연동**: `news` 컬렉션과 `meta/latest` 문서에 새 항목을 쓰면 페이지를 다시 배포하지 않아도 앱에 반영됩니다
